# 📈 Simulador de Reserva Financeira e Juros Compostos

Projeto desenvolvido para a disciplina de **Educação Financeira / Matemática** da **1ª Série do Ensino Médio**.

## 📌 Objetivo do Projeto
Demonstrar na prática o impacto dos aportes anuais e dos **juros compostos (5% ao ano)** no crescimento do patrimônio pessoal ao longo de 7 anos (dos 18 aos 24 anos de idade)[cite: 2].

## 📊 Premissas da Simulação
* **Período:** 2026 a 2032[cite: 2]
* **Salário Inicial (2026):** R$ 1.500,00 (com reajuste de 10% ao ano)[cite: 2]
* **Reserva Anual:** 12% do salário anual[cite: 2]
* **Taxa de Juros:** 5% ao ano sobre o valor inicial acumulado[cite: 2]
* **Saldo Final em 2032:** **R$ 1.949,82**[cite: 2]

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e tabela de dados financeiros.
* **CSS3:** Layout responsivo e estilização da interface.
* **JavaScript & Chart.js:** Renderização de gráfico combinado (barras para aportes anuais e linha para o montante acumulado).

## 🚀 Como Visualizar
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web.
